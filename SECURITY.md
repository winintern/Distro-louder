# Security Policy

## Supported Versions

Мы actively поддерживаем следующие версии загрузчика.

| Version          | Supported          |
| ---------------- | ------------------ |
| V8.2x (latest)    | :white_check_mark: |
| V8.x (stable)    | :white_check_mark: |
| < V4.0           | :x:                |

**Примечание:** V7.x — это текущая версия . V6.x — предыдущая стабильная версия
