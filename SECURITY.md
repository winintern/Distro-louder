# Security Policy

## Supported Versions

Мы actively поддерживаем следующие версии загрузчика.

| Version          | Supported          |
| ---------------- | ------------------ |
| V6.x (latest)    | :white_check_mark: |
| V4.x (stable)    | :white_check_mark: |
| < V4.0           | :x:                |

**Примечание:** V6.x — это текущая версия с новым TUI‑дашбордом, поддержкой BSD и конфигурационным файлом. V4.x — предыдущая стабильная версия
